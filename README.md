## Datasets

This repository includes various datasets tailored for the STON programming language. Each dataset is structured to facilitate easy integration into your AI projects.

### Dataset Details

1. **dataset1.ston**: This dataset contains sample data for training AI models. It includes various features relevant to AI2001 projects.
   
2. **dataset2.ston**: This dataset focuses on testing and validation. It provides data that helps assess the performance of AI algorithms.

Each dataset comes with a README file that explains its structure, contents, and how to use it effectively.

## Usage

To use the datasets and source code, follow these steps:

1. **Download the files** from the [Releases section](https://github.com/Markosgabriell38/AI2001_Category-Source_Code-SC-STON/releases).
   
2. **Open your code editor** and load the `main.ston` file located in the `src/` directory.

3. **Modify the code** as needed to fit your project requirements. Use the datasets by importing them into your STON scripts.

4. **Run your scripts** to test the AI models with the provided datasets.
